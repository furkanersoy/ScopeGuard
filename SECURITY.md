# Security policy

ScopeGuard's demo API intentionally contains an insecure endpoint. It is a local teaching fixture, not a production service. Keep it bound to `127.0.0.1`; do not expose it to a network or use real credentials/data.

The project is in an early prototype stage and does not yet accept vulnerability reports through a dedicated private channel. Do not include real secrets, personal data, or details of systems you are not authorized to test in public issues.
