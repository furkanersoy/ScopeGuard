# Güvenlik Politikası

ScopeGuard beta aşamasındadır. Güvenlik düzeltmeleri `master` dalındaki en güncel kaynak kod için sağlanır.

[Read the English security policy](SECURITY.md).

## Güvenlik açığı bildirimi

GitHub'ın [özel güvenlik açığı bildirim sayfasını](https://github.com/furkanersoy/ScopeGuard/security/advisories/new) kullanabilirsin. Bu seçenek, depo sahibi **Settings → Security and quality → Advanced Security** bölümünden private vulnerability reporting özelliğini etkinleştirdikten sonra kullanılabilir.

Özel bildirim seçeneği görünmüyorsa teknik ayrıntıları herkese açık issue'larda paylaşma. Hassas ayrıntı göndermeden özel bir iletişim kanalı istemek için depo sahibinin GitHub profilindeki iletişim bilgilerini kullan.

Gerçek kimlik bilgileri, sırlar, kişisel veriler veya test etme yetkin olmayan sistemlere ait bilgileri paylaşma. ScopeGuard'ın demo API'sindeki savunmasız uç nokta yerel eğitim amacıyla bilerek eklenmiştir; sentetik kayıtlar kullanır ve `127.0.0.1` adresine bağlı kalmalıdır. Bu uç nokta, aracın kendisinde bir güvenlik açığı sayılmaz.
